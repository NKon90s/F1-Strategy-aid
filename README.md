# F1 Strategy Aid 
  
This project aims to serve as an aid for F1 tyre strategy decisions. It helps to determine the initial tyre and pit stop strategy via machine learning tools and race simulation techniques. The base data is data fetched from [OpenF1 Api](https://openf1.org/).
